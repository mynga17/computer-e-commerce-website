# 🛒 Computer E-Commerce Website

A simple computer e-commerce website developed as a university web development project.

The website focuses on presenting computer products such as laptops and computer mice through a multi-page HTML/CSS interface.

---

## 📌 Overview

This project was developed as an academic web development project during my university studies. It is a static multi-page computer e-commerce website built to practice HTML, CSS, page navigation, product presentation, and static web content management.

---

## ✨ Features

### 🏠 Home Page

- Store introduction
- Product categories
- Navigation between different sections

### 💻 Laptop Products

The website includes laptop products from several manufacturers, including:

- ASUS
- Dell
- HP

Each product category contains individual product pages.

### 🖱️ Computer Mouse Products

The website also includes several computer mouse products, including products from:

- Logitech
- Akko

### 📄 Product Pages

Individual HTML pages are used to present product information and product images.

### 📞 Contact Page

A separate contact page is included to provide basic store contact information.
